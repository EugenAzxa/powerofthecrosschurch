# Memory wall portraits

The six portraits in place came from the St Archangel Gabriel project
(`~/Desktop/3d-ortdox-church/assets/portraits/`), re-cropped to 3:4 and matched
to the names by gender. The originals stay in that project; these are copies.

Replace any of them by overwriting the file - the names are fixed:

    p1.webp   Мария Ковальчук
    p2.webp   Пётр Савчук
    p3.webp   Анна Демчук
    p4.webp   Иван Мороз
    p5.webp   Ольга Гринчук
    p6.webp   Николай Бондарь

Portrait crop, roughly 3:4, about 600x800 is plenty. WebP or JPG (change the
extension in `tools/build.py` if you use JPG).

Any file that is missing simply does not load - the `<img>` removes itself and
the monogram shows instead, so the wall never renders broken.

## Before you add any

**Check for watermarks.** Two of the portraits sent for this wall carried a
visible stock-library watermark. A watermark on a church's memorial wall reads
as carelessness, and using the image without a licence is a real problem.

**Check the likeness.** These six people are fictional. Putting a photograph of
a real, identifiable person beside an invented name, an invented death date and
an invented life is a misuse of that person's likeness, whatever the disclaimer
says a paragraph above. Use images you have the right to use and that are not a
real identifiable individual - properly licensed stock, or generated portraits.
